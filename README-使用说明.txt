  CtrlC++ — 剪贴板历史工具  使用说明
═══════════════════════════════════════════════════

【快速上手】

1. 双击 CtrlCpp.exe 启动。程序会在后台运行，首次启动
   会在屏幕右下角弹出提示气泡。

2. 按 Ctrl + 空格键，即可打开剪贴板历史窗口；再按一次关闭。
   （快捷键可以在 设置 → 常规 里自定义成其他组合键）

   说明：这个快捷键不会影响日常的复制粘贴操作，也不会
   打出空格。注意：如果快捷键和输入法的"中/英切换"键
   相同，该切换键会被本程序占用。

3. 在历史窗口中：
   · 单击任意一条记录（或按回车）→ 内容自动粘贴回你
     刚才使用的程序里
   · 图片记录显示低分辨率大图预览，粘贴时仍使用原始图片
   · 复制 JPG/PNG/BMP/GIF 图片文件时也显示内容预览，粘贴仍为原文件
   · 鼠标拖动窗口空白处或底部状态栏，可移动窗口位置
   · 顶部搜索框可按文字 / 链接筛选记录
   · 鼠标滚轮支持像素级平滑滚动
   · 按 Del 键（或右键 → 删除）可删除选中的记录
   · 按 Esc 键或点击窗口外部关闭窗口

4. 托盘图标（屏幕右下角 ^ 展开后）：
   · 左键点击 → 打开历史窗口
   · 右键 → 设置 / 历史记录 / 退出

【设置说明】

右键托盘图标 → 设置，可以调整：

· 打开历史窗口的快捷键：默认 Ctrl + 空格。点击输入框后
  直接按下想要的组合键即可（如 Ctrl+B、Alt+Q），单独的
  F1~F12 功能键也可以；普通按键必须搭配 Ctrl 或 Alt。
  旁边有"恢复默认"按钮
· 开机自动运行：随 Windows 启动自动在后台运行
· 保留天数：默认 3 天，超过 3 天的记录自动删除（1~30 天可调）
· 缓存上限：默认 3072 MB（3 GB）。缓存超过上限时，
  自动从最旧的记录开始清理，直到低于上限
· 排除应用：不记录某些程序的复制内容（例如密码管理器、
  聊天软件）。可从正在运行的程序中直接选择，也可手动
  输入程序名（如 wechat.exe）
· 检查更新：从 GitHub 仓库查询最新版本；有新版本时可点
  "下载并安装"，程序会校验文件后自动退出、替换并重启，
  历史记录和设置都不会丢失
· 立即清空全部历史：一次性删除所有记录

【创建桌面快捷方式】

右键 CtrlCpp.exe → 发送到 → 桌面快捷方式。
也可以把 exe 固定到任务栏：右键任务栏图标即可看到
"设置 / 历史记录" 快捷入口。

【数据存放位置】

所有记录保存在（不占用 C 盘以外任何位置）：
  C:\Users\<你的用户名>\AppData\Local\CtrlCpp\

【常见问题】

Q: 在管理员权限的程序（如任务管理器）里按快捷键没反应？
A: 这是 Windows 的安全机制（UIPI）——普通权限程序无法
   监听管理员窗口的按键。如需支持，可右键 CtrlCpp.exe
   → 属性 → 兼容性 → 勾选"以管理员身份运行此程序"。

Q: 设置的快捷键和别的软件/输入法的组合键冲突了？
A: 本程序会优先占用该组合键，对方会失效。换一个别的
   软件不常用的组合即可（在设置里重新录制）。

Q: 复制图片后历史里显示的是图标而不是缩略图？
A: 正常现象。个别程序复制的图片格式特殊，无法生成预览，
   但粘贴功能不受影响。

Q: 微信等工具截的图，在历史里预览是黑色的？
A: 新版本已修复。这类截图的透明度通道为空但颜色数据正常，
   现在会自动还原为正常颜色显示，粘贴仍是原始图片。

Q: 滚轮方向和系统设置不一致？
A: 新版本已与系统设置保持一致（包括鼠标"反转滚动方向"
   和触控板滚动方向），会自动跟随。

Q: 检查更新显示"检查失败"？
A: 通常是网络无法访问 GitHub。检查网络或代理后重试；
   也可直接到项目页面手动下载安装包。

Q: 杀毒软件提示风险？
A: 本程序未做数字签名，个别杀软可能误报，添加信任即可。

Q: 如何彻底卸载？
A: 托盘图标右键 → 退出，然后删除 exe 文件和上面提到的
   CtrlCpp 数据文件夹，再到"设置 → 应用"里检查是否残留
   开机自启项（CtrlCpp），有则删除。
